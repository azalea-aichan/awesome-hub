Upload requirements
  • Upload one .html or .htm file, up to 5 MB.
  • Inline scripts and styles work; external files are blocked. API calls work only for hosts listed in API hosts.
  • The page runs isolated from the hub. Use ZIP static site for multiple files.
Upload requirements
  • ZIP must contain index.html at the root or inside public/.
  • node_modules/ folders are skipped.
  • Maximum ZIP: 100 MB; extracted site: 150 MB; 1000 entries.
  • Each site uses its own port; that port must be reachable from your device.
Upload requirements
  • The hub runs the project with Node.js. It needs server.js (or main in package.json, index.js, app.js).
  • The app must listen on process.env.PORT on all interfaces. The hub assigns the port.
  • Runtime dependencies in package.json are installed automatically.
  • Only upload projects you trust: the code runs on this server.
  • Deleting the card stops the app and deletes its files.
